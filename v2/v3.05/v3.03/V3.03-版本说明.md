# V3.03 版本说明

## 相比 V3.02 的改动

### Phase 1C：打磨收尾 + 代码审查修复

**新增文件：**
- `backend/translation/reflection.py` — 翻译反思优化（翻译后 AI 自审修正）
- `backend/core/video_downloader.py` — yt-dlp 视频下载
- `docs/phase1b-multi-model-spec.md` — Phase 1B 技术规格（从 V3.02 复刻）

**修改文件：**
- `backend/core/qwen_asr_runner.py` — 长音频按 Whisper segment 边界分段切分（5s 发音缓冲，15 分钟一批），解除 MLX 20 分钟单次调用上限
- `backend/core/sensevoice_runner.py` — 同理，长音频分段处理
- `backend/core/sentence_splitter.py` — `pre_splits` 未覆盖的段回退规则断句，修复 F4
- `backend/core/subtitler.py` — 新增 `mux_subtitles()` 软字幕封装
- `backend/translation/orchestrator.py` — 恢复翻译 prompt（去除 AI 拆长句要求），删掉子编号解析，修复 F1
- `backend/worker.py` — 反思优化已接入管线，LLM 失败自动降级，耗时写入异常路径，版本号写入日志头
- `backend/main.py` — 新增 `/api/download-video` 端点，`_config_hash` 默认值匹配
- `frontend/index.html` — 输出模式三选一（烧录/封装/仅 SRT）

**核心改进：**
1. 翻译和断句解耦——翻译阶段只做翻译，字幕生成阶段独立用规则断句
2. 长音频分段处理，不会超出 Qwen3/SenseVoice 单次上限
3. 软字幕封装，视频流不用重新编码
4. 翻译反思自动修正，quality 模式下翻译质量额外优化
5. yt-dlp 视频下载已接入 API
6. 日志里写版本号和总耗时
7. F1/F3/F4/F5 代码审查发现的 bug 全部修复
8. 159 测试全过

**已知限制：**
- Qwen3-ASR MLX 长音频切分逻辑已在代码中，但未在超过 20 分钟视频上实测
- Windows Qwen3 时间戳拆句（方案 B）留到 V4 打包阶段
