| 步骤 | 状态 | 观察 |

### 进度上报验证

进度消息格式正确：
```json
{"type":"progress","stage":"transcribe","percent":14,"message":"正在识别语音… 已识别 30 段","detail":"模型: tiny"}
```

- `stage` 字段正确切换（extract → transcribe → translate → subtitle → burn）
- `percent` 映射合理（extract:0-5, transcribe:5-35, translate:35-80, subtitle:80-90, burn:90-100）
- `message` 对用户友好（中文大白话，"正在识别语音… 已识别 30 段"）
- `detail` 补充技术信息

## 7. 测试覆盖盲区

以下场景未在本轮测试：

| 盲区 | 原因 | 风险 |
|------|------|------|
| 大文件上传 (>1GB) | 本地测试视频太小 | 流式上传逻辑未经压力测试 |
| 烧录 + libass | 测试参数设为 burn=false | 烧录管线未验证 |
| WebSocket 断线重连 | 需要浏览器 | 前端 reconnect 逻辑未验证 |
| 并发多任务 | 单任务测试 | worker_manager 并发安全性 |
| Windows 平台 | 当前在 macOS | 字体/路径/编码差异 |
| 网络错误翻译 | 无网络错误 | `_friendly_error` 未完全覆盖 |
| Baidu 翻译 API | 需 API Key | 双后端竞速未验证 |
| LLM 翻译 | 需 API Key | 7 个 LLM 后端均未验证 |
| 暗色模式 | 需浏览器 | CSS 媒体查询未验证 |
