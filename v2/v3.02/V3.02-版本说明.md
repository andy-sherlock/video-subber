# V3.02 版本说明

## 相比 V3.01 的改动

### Phase 1B：三模型转录 + 五层幻觉过滤

**新增文件：**
- `backend/core/hallucination_filter.py` — 五层幻觉过滤器（69 测试覆盖）
- `backend/core/hardware_detector.py` — 硬件检测 + 三档调度
- `backend/core/sensevoice_runner.py` — SenseVoice 声音分类
- `backend/core/qwen_asr_runner.py` — Qwen3-ASR 交叉验证
- `docs/phase1b-multi-model-spec.md` — 技术规格

**修改文件：**
- `backend/transcriber_v2.py` — 三模型并行管线 + Segment 新属性
- `backend/worker.py` — transcriptionTier 配置 + LLM 失败自动降级 + 日志版本号/耗时
- `backend/main.py` — /api/hardware 端点 + DELETE 保留日志 + JSON 解析修复
- `backend/env_check.py` — 新增 SenseVoice/Qwen3 检测
- `backend/translation/orchestrator.py` — LLM 逐段翻译改为降级链串行
- `frontend/index.html` — 三档转录选项 + 环境栏新增两项

**核心改进：**
1. 三模型并行：Whisper + SenseVoice + Qwen3-ASR 同时跑（≥16GB 内存）
2. 五层幻觉过滤：硬过滤（声音分类 + 正则 + 去重）+ 软标记（交叉验证 + 语速）
3. 语言自动传递：Whisper 检测语言 → 过滤器阈值自动匹配
4. LLM 修复：非上下文感知路径不再并发竞速，使用降级链
5. LLM 全失败 120s 超时自动降级免费引擎
6. 日志版本号 + 耗时汇总

**已知限制：**
- Qwen3-ASR MLX 单次最大处理 20 分钟音频（Phase 1C 加切分）
- Windows 版 Qwen3 时间戳对齐待打包时切换
