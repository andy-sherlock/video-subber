# Video Subber V1.3 — 最终版本（V1 线终点）

**版本基础**：从 V1.2 复制。V1.3 是 V1 主版本线的最终版本，后续 V2/V3/V4 以此为框架，不应改动 V1.3 锁定的功能。

---

## V1.3 相比 V1.2 的核心变更

### 1. 单趟自适应阈值（Jobs 方案）

**问题**：V1.2 的物理特征阈值硬编码在 FILTER_CONFIG 中。换一个音频类型（如从电话录音切换到面对面采访），阈值可能水土不服。之前手动校准（P029）需要人工选段、测数值、改配置。

**方案**：每个视频用自己的物理特征分布动态算阈值。不存盘，不跨视频复用。

**实现**：
- `_compute_features(y, sr)` — 提取 4 个物理特征原始值（不投票）
- `_is_music_like(feats, thresholds)` — 用已算特征 + 阈值投票
- `_find_dynamic_thresholds(feats_list)` — 从当前视频分布自动找音乐/对话分界线

**流程**：Whisper 吐段时顺手算特征并暂存（一趟）→ 全部吐完后，用所有段特征分布动态算阈值 → 同一批数据原地过滤。每个段的物理特征只算一次，零额外计算。

**安全钳**：
- 间隙检测只在低值区（下半部分）找——音乐特征永远比对话低
- 单峰检测：低值区最大值/最小值 < 3x → 退回默认值
- 只紧不松：动态阈值不能比默认值松（`min(动态, 默认)`）

### 2. 四信号多数投票

V1.2 使用三信号投票（RMS 方差 + 频谱质心 + 零交叉率）。V1.3 加入第四信号——频谱峰度（kurtosis），用于区分鼓点/打击乐和对话。

### 3. FILTER_CONFIG 统一配置

所有阈值收进一个 dict，一处修改全局生效：

```python
FILTER_CONFIG = {
    "rms_var":   0.0005,  # RMS 能量方差（2026-05-21 电话音频实测校准）
    "cent_mean": 1200,    # 频谱质心均值
    "zcr_mean":  0.06,    # 零交叉率均值（2026-05-21 电话音频实测校准）
    "kurtosis":  1.5,     # 频谱峰度（> 此值 = 有共振峰 = 像音乐）
    "nsp":       0.6,     # no_speech_prob 阈值
    "intro_nsp": 0.2,     # L4 片头加强 nsp 保底
}
```

## V1.0 → V1.3 问题解决历程

| 版本 | 核心问题 | 解决方案 |
|------|---------|---------|
| V1.0 | 基础流水线 | faster-whisper + deep-translator + ffmpeg |
| V1.1 | P010 说话人合并、P013 片头幻觉、P015 VAD 误拦、P016 翻译失败、P017 关键词漏俄语 | VAD 废弃→五层后处理过滤、Baidu \n 批量翻译 + 双后端竞速、resemblyzer 说话人检测、多语言关键词 |
| V1.2 | P025 单信号过滤不可靠、P026 per-model 校准失效 | RMS 三特征双信号交叉验证、per-model 校准废弃统一 nsp=0.6、`[?]` 不确定标记、L2 重复字符比修复 |
| V1.3 | 阈值手动校准耗时、P026 跨视频阈值不通用 | 单趟自适应阈值、四信号多数投票、FILTER_CONFIG 统一管理、动态阈值只紧不松安全钳 |

## V1.3 锁定的功能（V2/V3/V4 不可改动）

| 模块 | 文件 | 锁定内容 |
|------|------|---------|
| 四层防线过滤 | transcriber.py | L1 双信号交叉验证 + L2 关键词 + L4 片头加强 + L5 最短长度 |
