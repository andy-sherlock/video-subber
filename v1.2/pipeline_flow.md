# V1.2 自动校准 + 双信号交叉验证 — 完整流程图

## ▸▸▸ 阶段 0: 自动阈值校准（calibrate_features.py，每个新视频/新音频类型跑一次）

```
视频文件 (test.mp4)
    │
    ▼
┌─────────────────────────────────┐
│ ffmpeg 提取音频                  │
│ → 16kHz mono PCM WAV            │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│ Whisper 转录 (无过滤, beam_size=5)│
│ → 所有 segment: start/end/text/nsp │
│   不管 nsp 高低，全部保留           │
│   (这一步的目的: 收集原始分布数据)    │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│ 对每个 segment 提取 4 个物理特征    │
│                                 │
│  chunk = audio[start*sr:end*sr] │
│                                 │
│  ① RMS 能量方差 (librosa)        │
│  ② 频谱质心均值 (librosa)        │
│  ③ 零交叉率均值 (librosa)        │
│  ④ 频谱峰度    (numpy FFT)      │
│                                 │
│  收集所有段的 4 组值 → 4 个数组    │
└────────────┬────────────────────┘
             │
             ▼
┌─────────────────────────────────┐
│ 自动找分界线 (gap detection)      │
│                                 │
│  对每组值排序，找相邻最大间隙:      │
│                                 │
│  RMS 方差:                       │
│  [0.00001 0.00002 0.00005 0.0001 │
│              ↑ 音乐聚集           │
│   0.0003 0.0008 │ 0.0015 0.0024  │
│                  ↑ 最大间隙       │
│  0.0031 0.0052 ...]              │
│              ↑ 对话聚集           │
│                                 │
│  阈值 = 间隙左边 + 30% 安全边距   │
│  → rms_var:   0.0005            │
│  → cent_mean: 1200  (不改)      │
│  → zcr_mean:  0.06             │
│  → kurtosis:  1.5   (不改)      │
└────────────┬────────────────────┘
             │
             ▼
    FILTER_CONFIG 输出
    (贴入 transcriber.py)
```
